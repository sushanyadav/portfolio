A minimal portfolio site focused on content and interaction. Built with Next.js 16, MDX for content, and Tailwind CSS for styling.

## Stack

- **Next.js 16** — App Router, RSC, Turbopack
- **MDX** — Content authored in markdown with embedded components
- **Tailwind CSS** — Utility-first styling with the typography plugin

## Approach

The goal was simplicity. No CMS, no database — just markdown files that compile at build time. Content lives alongside the code, making it easy to write and deploy in one flow.

Micro-interactions are used sparingly to make navigation feel responsive without being distracting.

A browser-based tool for manipulating variable font axes. Drag sliders to adjust weight, width, slant, and optical size — see changes in real-time across a specimen panel.

## Features

- **Live preview** — instant feedback on all axes
- **Specimen panel** — test at multiple sizes and contexts
- **Export** — copy CSS with the exact values you've set

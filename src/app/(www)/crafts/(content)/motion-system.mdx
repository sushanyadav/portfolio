A unified motion system built on spring physics. Every transition in the interface shares the same physical constants — mass, stiffness, damping — so movement feels consistent across components.

## Principles

- **Springs over duration** — animations respond to interruption naturally
- **Shared constants** — one set of physics for the whole system
- **Reduced motion** — graceful degradation, not removal
